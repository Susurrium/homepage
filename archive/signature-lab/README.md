# Signature Lab Archive

这里保存动态签名方案的历史实验页面、候选 SVG、源图和生成器导出文件。

这些文件不属于正式站点内容，因此从 `public/` 和 `src/pages/` 移出，避免被 Astro 构建、Pagefind 索引或 GitHub Pages 发布。当前首页只使用：

```text
public/images/signature-ink.png
src/components/DynamicSignature.astro
```

若需要重新启用实验页面，请先审核归档 HTML/SVG，再将所需资产有选择地恢复到公开目录；不要直接把整个 `assets/` 目录重新发布。
